# ماه‌بانو — طرح رابط کاربری (UI Concept)

اپلیکیشن ردیابی چرخهٔ ماهانهٔ بانوان با تقویم شمسی + حالت اختصاصی همسر («همراهِ ماه»).

## فایل‌های اصلی
| مسیر | توضیح |
|---|---|
| `screens/moonbanu-ui-design.html` | **گالری کامل ۱۳ صفحه** (خودکفا، آفلاین قابل نمایش) |
| `screenshots/00-overview.png` | تصویر کلی همهٔ صفحه‌ها در یک نگاه |
| `screenshots/01-...png` تا `13-...png` | اسکرین‌شات‌های تک‌تک صفحه‌ها (۳۹۰×۸۴۴ @2x) |
| `screens/moonbanu-style-guide.html` | **راهنمای طراحی و تحویل**: فونت، تمام کدهای رنگ، توکن‌ها، نمونهٔ زندهٔ دکمه‌ها و کامپوننت‌ها، فهرست تک‌تک دکمه‌ها و کارهای ۱۳ صفحه |
| `screens/moonbanu-blueprint.html` | نقشهٔ راه محصول: رنگ‌ها، موتور چرخه، دیتابیس، معماری فنی، نقشهٔ راه ساخت |
| `mockups/` | سورس قابل ویرایش: `style.css`، `components.py`، `jalali.py`، `screens_woman.py`، `screens_partner.py`، `build.py` |

## بازتولید اسکرین‌شات‌ها
```bash
cd mockups && python3 build.py          # رندر همهٔ صفحه‌ها → ../screenshots
python3 build_presentation.py          # گالری + تصویر کلی
python3 build_blueprint.py             # نقشهٔ راه
python3 build_styleguide.py            # راهنمای طراحی و تحویل
```
